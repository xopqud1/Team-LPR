## Kanban тақтасындағы жұмыс

| Баған | Қашан қолданылады |
| --- | --- |
| To Do | Тапсырма тіркелген, жұмыс басталмаған |
| In Progress | Орындаушы тапсырманы орындап жатыр |
| Review | Pull Request ашылып, тексеруді күтуде |
| Done | Өзгеріс негізгі тармаққа біріктіріліп, Issue жабылған |

Issue №7-ні осы тақтаға қосып, орындалу кезеңіне қарай жылжыту керек. Нақты мәртебе тақтаның өзінде тексеріледі; осы нұсқаулықтағы кесте карточканың жылжытылғанын дәлелдемейді. Аяқталмаған №3 және №5 тапсырмаларын Done бағанына ауыстыруға болмайды.

## Issue → branch → commit → Pull Request

№7 Issue-мен GitHub арқылы байланыстырылған тармақ:

```text
codex/issue-7-lab8-islambek
```

Жергілікті жұмыс реті:

```bash
git fetch origin
git checkout codex/issue-7-lab8-islambek
git add README.md docs/lab-8-islambek.md
git commit -m "Issue #7 орындалды"
git push origin codex/issue-7-lab8-islambek
```

GitHub-та осы тармақтан `main` тармағына Pull Request жасалады. Сипаттамасына автоматты жабу сілтемесі жазылады:

```text
Closes #7
```

Тексерулер сәтті аяқталғаннан кейін PR біріктіріледі. GitHub №7 Issue-ды автоматты жабады. Issue бетіндегі Development бөлімінен байланысты тармақ пен PR-ды көруге болады.

## GitHub Actions

Workflow файлы: [html-check.yml](../.github/workflows/html-check.yml).

Ол зертханалық жұмыста берілген үлгі бойынша `push` және `pull_request` оқиғаларында іске қосылады. `validate-html` тапсырмасы Ubuntu ортасында репозиторийді жүктеп, мына хабарламаны шығарады:

```text
HTML файлдары тексерілді
```

Бұл оқу үлгісі автоматтандырудың іске қосылуын көрсетеді. `echo` HTML синтаксисін тексермейді және сайтта қате жоқ екенін дәлелдемейді.

Нәтижені тексеру:

1. PR бетіндегі Checks бөлімін ашу.
2. `validate-html` тексеруінің `success` күйін көру.
3. Actions бөлімінен осы тармаққа немесе commit-ке сәйкес іске қосылуды ашу.
4. `HTML validation` қадамындағы хабарламаны тексеру.
5. PR біріктірілгенін, Issue жабылғанын және `main` тармағындағы іске қосылу нәтижесін тексеру.

№6 PR-дағы workflow екі тексеруден сәтті өтті. `islambek09` кодты қарап, PR-ды мақұлдап, негізгі тармаққа біріктірді; №4 Issue осы PR арқылы жабылды.

## Тапсыру алдында тексеру

- Репозиторийде кемінде үш Issue бар.
- №7 Issue авторы және орындаушысы — `islambek09`.
- Issue-да белгі, жоспарлы мерзім және түсіндірме бар.
- №7 Issue-мен байланысты тармақта commit және `Closes #7` сілтемесі бар PR жасалған.
- PR тексерулері сәтті, PR біріктірілген және Issue жабылған.
- Kanban карточкалары нақты орындалу күйіне сәйкес орналастырылған.

Соңғы үш тармақтың нәтижесі GitHub-та тікелей тексеріледі; құжаттағы нұсқаулық орындалу фактісін алмастырмайды.
