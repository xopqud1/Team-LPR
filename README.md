# Team-LPR

Командный проект — лабораторно-практическая работа №4.

## Описание

Данный проект представляет собой веб-сайт, созданный в рамках курса по веб-разработке. Включает HTML-разметку, CSS-стилизацию и JavaScript-интерактивность.

## Структура проекта

```
Team-LPR/
├── index.html                      # Главная страница
├── style.css                       # Стили
├── script.js                       # Скрипты
├── README.md                       # Описание проекта
└── Duisenov-favorite-hero.html     # Страница участника (ЛПР 6)
```

## Участники

- **Адам 1 (Диктатор)** — создал и поддерживает главный репозиторий
- **Адам 2 (Қатысушы / Contributor)** — добавил страницу с описанием любимого героя комиксов

## Использованные технологии

- HTML5
- CSS3 (Flexbox, Grid, Анимации)
- JavaScript (DOM, IntersectionObserver)
- Git & GitHub (Fork, Branch, Pull Request)
